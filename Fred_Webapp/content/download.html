Locality data downloads (Qmap areas)

Text files downloadable from this page are provided as a service to the NZ geological community, and contain, for over 83000 localities located in the GNS quarter million geological map series, the following information:

  • NZMS260-based fossil record number
  • NZMS260 truncated grid reference
  • equivalent NZMS1-based fossil record number and NZMS1 ("yard grid") truncated grid reference (for pre-1975 registrations)
  • FR Masterfile Centre, and comments on any registration or grid reference changes

This data is an amalgamation of NZMS1-based and NZMS260-based masterfile data to end-2000, and location amendments and later locality data resident in the GNS computer database in July 2000. Not all grid references have been checked for validity. The Fossil Record File also contains offshore registrations, which are not included here.

For collections which are curated at GNS Lower Hutt (and a few others), the laboratory prefix is also listed as a guide to the location of specimens and paleontological data. GNS laboratory prefixes, denoted by "GNS-" are described in the GNS Paleontological Collections Catalogue.
Other codens used so far are:

  • AU = Auckland University Geology Department
  • BPS = BP Sunbury palynology collection, held at GNS Lower Hutt
  • FIELD = field identifications
  • OU = University of Otago Geology Department
  • VUWG = Victoria University of Wellington Geology Department

The files are "zipped" versions of comma-delimited files.

These files will be updated, or replaced with a customisable service when we have the opportunity.
